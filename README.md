# SouthPoint Solutions website

Static site (HTML, CSS, JS). No build step.

## Deploy on GitHub Pages
1. Create a repository and upload everything in this folder to the root (index.html must be at the top level).
2. Settings > Pages > Deploy from a branch > main, folder / (root).
3. The site goes live at https://USERNAME.github.io/REPO/. For a custom domain, add it under Pages and add a CNAME record at your DNS provider.

## Before launch
- Replace hello@southpoint.example and the placeholder phone number in contact.html and the footer of each page.
- Contact form: currently opens the visitor's email app. For real lead capture, point the form at Formspree or similar.
- Add a Calendly or Cal.com embed in the booking block on contact.html.
- Verify the SouthPoint Solutions name (company, trademark, domain) before launch.
